# BossRaid

> 최대 4명의 플레이어가 함께 보스를 공략하는 3D 백뷰 협동 액션 게임

보스의 공격 범위를 확인하고 회피하며, 각자의 공격과 스킬을 활용해 보스를 처치합니다. 마을에서 전투를 준비하고 보스에 도전하는 레이드 사이클을 반복합니다.

## 실행 방법

### 멀티플레이 실행 절차

1. 게임 실행 파일(.exe)을 두 번 실행합니다.
2. 서로 다른 계정으로 로그인합니다.
3. 한쪽에서 방을 생성하고, 다른 쪽에서 같은 방에 입장합니다.
4. 준비 완료 후 방장이 시작합니다.

### 설정 파일

- 입력: `Assets/Wang/03_Input/PlayerInput.inputactions`
- Photon: `Assets/Photon/PhotonUnityNetworking/Resources/PhotonServerSettings.asset`
- Firebase: `Assets/google-services.json`

### 조작법**

| 행동 | 입력 |
| :--- | :--- |
| 이동 | `W` `A` `S` `D` |
| 시점 조작 | 마우스 이동 |
| 스킬 | 숫자 `1` / `2` / `3` / `4` / `5` / `6`|
| 구르기 | `Space` |
| 점프 | `F` |


## 핵심 플레이 흐름

**로그인 → 방 찾기 → ROOM → 마을 → 보스전 → 마을 복귀**

| 단계 | 플레이 내용 |
| :--- | :--- |
| 로그인 | 로그인 화면에서 게임에 진입합니다. |
| 방 찾기 | 함께 플레이할 방을 찾습니다. |
| ROOM | 캐릭터를 선택하고 레디를 완료해 게임을 시작합니다. |
| 마을 | 스킬을 강화하고 아이템을 구매합니다. |
| 보스전 | 보스의 공격을 회피하고 공격과 스킬로 보스를 공략합니다. |
| 결과 및 복귀 | 승리 시 포인트를 획득하고, 패배 시 보상 없이 마을로 복귀합니다. |

**마을 → 보스전 → 결과 처리 → 마을 복귀**를 반복하는 구조입니다.

## 주요 기능

- **4인 협동 레이드** — 최대 4명의 플레이어가 협력해 보스를 공략합니다.
- **공격 범위 확인과 회피** — 보스의 공격 범위를 확인하고 회피하며 전투를 진행합니다.

| 기능 | 내용 |
| :--- | :--- |
| 사용자 인증 | Firebase Authentication 기반 이메일 회원가입·로그인 및 익명 로그인 |
| 멀티플레이 접속 | Photon PUN을 이용한 최대 4명 방 접속 |
| 보스 AI | 타겟 탐색 → 이동 → 스킬 선택 → 실행 → 대기 반복 |
| 스킬 선택 | 거리에 따라 공격 후보를 구분하고 직전 사용 스킬 제외 |
| 보스 공격 | 내려치기·꼬리치기·돌진·운석·충격파 |
| 공격 예고 및 피격 판정 | 장판으로 공격 범위를 표시하고, 공격당 플레이어별 중복 피해 방지 |
